# 工作台集成验收清单

本文保留此前 Mac/Electron 与 oil creator 候选组合的验证输入。先通过具体业务内容工作台交付积累
经验，再归纳自有工作台产品，本仓具体体系尚未开始搭建；后续确定采用范围后再更新和执行本清单。
本清单不是内容工厂的前置条件，不要求暂停业务工作台交付，也不构成本仓产品化开工指令。
下列能力均不表示已实现。执行结果、具体版本与缺陷记录到相应 PR，不把本清单当作实时任务状态表。
方向见[产品方案](product-plan.md)，上游事实快照见 [UPSTREAM](../UPSTREAM.md)。

## 1. 固定可用的组合

2026-08-30 核对快照中的 oil creator 声明 DSH rc.6/rc.7，而 Desktop 源码依赖 0.1.2-alpha.1，尚无组合测试。
先选择共同兼容的版本或完成显式适配，不能强制忽略 peerDependencies、复制两套冲突的 DSH 服务，
也不能把版本范围不一致直接断言为运行失败。

记录 Node/Electron、DSH、Desktop、oil creator、附加 Skill 的版本/commit、来源、许可与安装校验值。
先验证干净 profile 的安装、加载与移除，再测试升级后的状态保留；禁止对用户现有全局 profile 做试验。

## 2. 侧栏与桌面兼容

- oil creator 的 bundle 会禁用官方 `ui-sidebar`；验证目标 Desktop 模式中的内容列表、检查器、对话和设置都能正常使用。
- Desktop 的兼容模式可作为初始评估对象，但不能预先认定兼容；切换模式、重启与插件卸载后检查官方界面恢复。
- 安装与卸载只管理应用所属的插件装配，不向用户全局 patch 写入不能随卸载还原的配置。
- 不把 Electron 或任意系统执行接口暴露给渲染页面；验证外链、内容预览和插件请求的权限边界。

## 3. 内容与知识库

- 验证同一个 Markdown 文件在工作台和 Obsidian 中编辑，变更能被观察，正文不会被复制为互相冲突的隐藏副本。
- 验证 Vault 内目录、Vault 外目录、中文/空格路径、移动或重命名、附件引用、同时编辑冲突与恢复。
- 图文项目无视频仍可完成；音频项目无录屏工程仍可完成；视频项目按实际能力完成自己的步骤。
- 一个项目可包含多种媒体，完成条件分别对应真实文件与用户审核结果，不套用视频阶段推导所有内容。
- 不默认读取整个磁盘，不自动合并原有知识库，不导入作者人设、账号或其他真实业务项目。

## 4. 插件、Skills 与执行

- 核心内容列表、笔记与对话在可选外部工具缺失时仍可使用；只禁用相关操作并给出准确原因。
- 验证 AI 辅助配置的只读检查、安装来源/版本、权限与费用预览、确认执行、失败回退和移除。
- 凭据只通过受控凭据服务处理，界面只显示配置状态；日志、诊断包和 Git 不含凭据明文。
- 任务启动返回、任务完成、产物可读、人工审核是不同状态；错误或结果未知时不盲目重试付费或上传动作。
- 工作台只维护内容级流程，模型任务状态和账务使用所接入服务的真实结果，不复制公共 API 的责任。
- 上传、平台草稿、最终发布和数据回收分别授权；未授权时不得因为安装了 Skill 就执行。

## 5. Mac 生命周期与隔离

- 干净环境双击启动，应用自带所需运行环境或受控安装流程，不要求用户已有 Node、pnpm 或全局 `dsh`。
- 端口被占用、连续双击、异常退出后重开都不会误连其他服务、误杀其他进程或留下僵尸实例。
- 重要设置在随机端口重启后保留；检查依赖 localStorage 的插件，不把 origin 改变当成用户主动重置。
- 应用标识、配置、凭据作用域、插件状态与更新渠道独立；不得继续使用上游产品或另一个产品的默认身份。
- 分别验证关窗口继续任务、退出应用、主动停止、崩溃、断网、休眠与唤醒，说明哪些任务能恢复，哪些需要用户处理。
- 菜单栏能看到活动任务与失败状态，退出前提示影响；不开启未经授权的开机自启或独立后台守护。
- 记录 Apple Silicon 上的实测结果；Intel Mac 若未测须明确标注，跨平台框架不等于其他平台已经通过。

## 6. 安装、升级、移除与公开边界

- 在不依赖开发目录的签名/公证安装包中测试启动；更新包来源与完整性受验证，升级失败可恢复。
- 明确整包更新与插件更新的兼容关系，禁止运行中无提示变更依赖；数据迁移前备份并验证恢复。
- 移除插件恢复原界面；卸载应用保留用户正文和成品，不删除整个 Vault、共享配置或其他应用数据。
- 验收使用本地临时合成材料，不建立真实业务案例展示；公开日志和截图另做隐私检查。
- 依次报告源码/本地检查、打包、签名/公证、安装启动、插件兼容、真实媒体流程和用户验收；不互相代替。
