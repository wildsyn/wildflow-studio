# 版本与发行

当前只有治理骨架，没有可启动的应用、安装器、已验证 DSH Bundle 或可发行产品版本。
内容工厂持续打磨；先通过具体业务内容工作台交付积累经验，再归纳本仓自有产品。
本仓具体体系尚未开始搭建，没有工作台发行日期承诺；后置本仓产品化不影响业务工作台交付。
方向及此前候选方案见[产品方案](product-plan.md)。

未来发行须逐项提供：
1. 精确源码 revision、DSH/OB/插件依赖版本、许可与来源。
2. 全新环境安装、重复安装、升级冲突、失败恢复和卸载保留用户数据的验证。
3. 所声明图文、音频、视频能力的真实任务证据，不能以目录或 Mock 代替。
4. 运行位置、后台生命周期、权限、费用、数据流和人工审核/发布边界。
5. 可回退产物与用户配置迁移说明。

仓库已获准公开并采用 MIT；Tag、Release、npm 发布或生产部署仍需负责人明确授权。
本仓不复制模型账户、余额、计费或 GPU 推理供给实现。用户资料不进入发行物。
